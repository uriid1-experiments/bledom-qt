# bledom-qt

[English version](README.md)

Qt6-приложение для управления светодиодной лентой с контроллером **ELK-BLEDOM** по Bluetooth LE.

Возможности:

- Сканирование BLE-устройств или подключение по MAC-адресу
- Вкл/выкл, цвет RGB (диалог с живым предпросмотром на ленте, пресеты, слайдеры), яркость
- 22 встроенных эффекта с регулировкой скорости
- Синхронизация времени и поле для отправки произвольного hex-пакета
- Лог всех отправленных пакетов
- Интерфейс на английском и русском, переключается на лету через меню **Язык**
- Режим командной строки для скриптов и хоткеев
- Запоминает MAC, цвет, яркость и язык между запусками

## Сборка

Зависимости: Qt 6 (`Core`, `Gui`, `Widgets`, `Bluetooth`, `LinguistTools`), CMake ≥ 3.21, Ninja.

Arch / Manjaro:

```sh
sudo pacman -S qt6-base qt6-connectivity qt6-tools cmake ninja
```

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/bledom-qt
```

## Использование

**GUI:** нажать **Сканировать**, выбрать `ELK-BLEDOM` (или ввести MAC вручную), нажать **Подключить**.
Все блоки ниже панели подключения активируются, когда устройство готово.

**CLI:**

```sh
bledom-qt -c BE:60:C6:00:05:1B                                   # открыть GUI сразу подключённым
bledom-qt -c BE:60:C6:00:05:1B --power on --color ff8800 --brightness 80 --quit
bledom-qt -c BE:60:C6:00:05:1B --power off --quit
```

`--quit` выполняет команды без окна и завершает работу (код 0 при успехе, 2 при таймауте).

## Локализация

Исходный язык — английский. Переводы лежат в `i18n/bledom-qt_<lang>.ts`
и встраиваются в бинарник как ресурсы Qt.

После изменения или добавления строк в `tr()`:

```sh
cmake --build build --target update_translations   # обновить .ts
# отредактировать i18n/bledom-qt_ru.ts (Qt Linguist или любой редактор)
cmake --build build                                 # .qm пересоберутся сами
```

Чтобы добавить язык, допишите его код в `I18N_TRANSLATED_LANGUAGES` в `CMakeLists.txt`
и в `Language::available()` в `src/Language.cpp`.

## Протокол ELK-BLEDOM

Сервис `0000fff0-…`, характеристика записи `0000fff3-…` (write without response).
Каждый пакет — 9 байт: `7E 00 <cmd> <a> <b> <c> <d> 00 EF`.

| Команда        | Пакет                                               |
|----------------|-----------------------------------------------------|
| Включить       | `7E 00 04 F0 00 01 FF 00 EF`                        |
| Выключить      | `7E 00 04 00 00 00 FF 00 EF`                        |
| Цвет RGB       | `7E 00 05 03 RR GG BB 00 EF`                        |
| Яркость 0–100  | `7E 00 01 NN 00 00 00 00 EF`                        |
| Эффект         | `7E 00 03 EE 03 00 00 00 EF` (EE = 0x87…0x9C)       |
| Скорость 0–100 | `7E 00 02 NN 00 00 00 00 EF`                        |
| Время          | `7E 00 83 HH MM SS DD 00 EF` (DD = день недели 1–7) |

## Структура

- `src/BledomDevice.{h,cpp}` — BLE-слой: скан, подключение, очередь команд (схлопывает поток событий от слайдеров).
- `src/MainWindow.{h,cpp}` — GUI на QtWidgets.
- `src/Language.{h,cpp}` — переключение языка на лету.
- `src/main.cpp` — разбор аргументов командной строки.
- `i18n/` — исходники переводов.
